Changes to the original dataset in this image:
- Uncompressed the canonical four IDX files after SHA256 verification.
- Converted each raw pixel into a signed i8 mantissa representing the project's
  established input mapping: round((pixel/255)*254 - 127), with dyadic shift 7.
- Retained all original observations in their original order and preserved
  original class labels byte-for-byte.
- Generated a deterministic manifest recording the pinned source SHA256 hashes,
  transformed hashes, and the previously established 55k/5k split definition.
